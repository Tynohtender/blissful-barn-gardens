# Blissful-Barn-Events-Gaden-Site

## 📖 Overview
A responsive website with an event booking system and reservation functionality. 

## ✨ Features
- Booking System
- Responsive social icons / links
- Customized galley
- Live map/location for the site

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript
